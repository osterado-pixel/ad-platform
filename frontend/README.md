# Сайт Ad Platform (Next.js)

Лендинг и страница AI-копирайтера. Кабинет рекламодателя и администратора — встроенный интерфейс
бэкенда `/app`; сайт и кабинет работают на одном домене, поэтому вход общий.

Языки: английский (по умолчанию), русский, немецкий — адреса `/en/…`, `/ru/…`, `/de/…`. Адрес без языка
(`/`, `/generate`) открывается на языке, выбранном в переключателе (cookie `lang`), иначе — на языке браузера,
иначе — на английском (`src/proxy.ts`). Поисковикам — ссылки на все языковые версии (`hreflang`).

| Страница | Что |
|---|---|
| `/` | Лендинг: первый экран, живое демо AI-копирайтера (гостю — пример ответа, после входа — настоящая генерация), как работает, цены, вопросы |
| `/generate` | AI-копирайтер: запуск фоновой задачи и опрос статуса (`src/hooks/useAdTask.ts`) |

Всё остальное (`/api`, `/app`, `/widget.js`, `/demo`, `/docs`) — бэкенд: на боевом сервере эти пути
отдаёт Caddy, при разработке и без Caddy — `rewrites` в `next.config.ts` (адрес — `BACKEND_URL`).

## Переводы

Тексты — в словарях `src/i18n/dictionaries/{ru,en,de}.json` (русский задаёт структуру). Новый язык —
код в `src/i18n/config.ts` и файл словаря. `npm run check:i18n` проверяет, что во всех словарях есть все
ключи и те же подстановки (`{amount}`, `{n}`), — запускается и в CI. Немецкий перевод перед запуском
стоит вычитать носителю языка.

## Разработка

Нужны Node.js 20.9+ и запущенный бэкенд на `http://127.0.0.1:8000`.

```bash
npm install
npm run dev        # http://localhost:3000
npm run check:i18n # полнота переводов
npm run lint
npm run build      # продакшн-сборка (.next/standalone)
```

## Docker

```bash
docker build -t ad-platform-frontend .                                  # бэкенд — сервис api в compose
docker build --build-arg BACKEND_URL=http://host.docker.internal:8000 .  # бэкенд на этой машине
```

Адрес бэкенда вшивается при сборке. Образ — только `standalone`-сборка, запуск не от root.
